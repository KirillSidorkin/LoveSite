# 💌 Признание в любви

Одностраничный романтический сайт: приветствие с именем, письмо-признание, карточки «За что я тебя люблю» и финальный вопрос с салютом из сердечек.

Всё в одном файле `index.html` (HTML + CSS + JS), без библиотек — только шрифты Google Fonts. Работает на телефоне и компьютере.

## ✨ Что внутри

- **Экран-приветствие** — имя появляется по буквам, кнопка «Открыть моё сердце»

- **Письмо** — слова проявляются по мере прокрутки

- **6 причин** — карточки переворачиваются при наведении или касании

- **Финал** — пульсирующее сердце, вопрос «Ты будешь со мной навсегда?», салют и дождь из сердечек после «Да» (и шуточная убегающая кнопка «Нет»)

- Плывущие сердечки на фоне, параллакс, сердечки при клике в любом месте

## ✏️ Как изменить под себя

Откройте `index.html` в любом текстовом редакторе.

| Что меняем | Где искать |
| - | - |
| Имена | `const CONFIG` → `herName`, `myName` |
| Тексты письма, карточек, финала | `const CONFIG` → `welcome`, `letter`, `reasons`, `final` |
| Цвета и шрифты | блок `:root` в начале `<style>` (помечен 🎨) |
| Количество сердечек, длительность салюта | `CONFIG.effects` |
| Убрать кнопку «Нет» | `CONFIG.final.showNoButton: false` |


В любом тексте можно писать `{her}` и `{me}` — они автоматически заменятся на имена.
